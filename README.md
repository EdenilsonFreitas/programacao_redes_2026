2. Principais tipos de redes
LAN (Local Area Network): rede local, como em casas, escolas e empresas.
MAN (Metropolitan Area Network): conecta redes dentro de uma área metropolitana.
WAN (Wide Area Network): conecta redes em grandes distâncias.
WLAN: rede local sem fio, geralmente utilizando Wi-Fi.

5. Principais protocolos
TCP/IP: base da comunicação na Internet.
HTTP/HTTPS: acesso a páginas e serviços web.
DNS: transforma nomes de sites em endereços IP.
DHCP: distribui endereços IP automaticamente.
FTP: transferência de arquivos.
6. Topologias de rede
Estrela: todos os dispositivos se conectam a um equipamento central.
Barramento: os dispositivos compartilham um mesmo meio de transmissão.
Anel: os dispositivos são conectados formando um circuito.
Malha: os dispositivos possuem várias conexões entre si.

10. Conclusão

As redes de computadores são fundamentais para a comunicação e o compartilhamento de informações. Elas estão presentes em casas, escolas, empresas e na Internet, permitindo que diferentes dispositivos se comuniquem de forma rápida e eficiente.

Além disso, a segurança das redes é essencial para proteger dados e sistemas contra ameaças. Com o avanço da tecnologia, as redes continuam evoluindo e se tornando cada vez mais importantes no cotidiano.
